# Gassenplan

Hallenplan mit 31 Gassen (rechts 1–19 von vorne nach hinten, links 20–31 von hinten nach vorne),
Modellen und Chargen. Läuft im Browser und als Home-Bildschirm-App ohne Internet.

App: https://g8ty6c6mj8-wq.github.io/

Einträge werden nur auf dem jeweiligen Gerät gespeichert. Geteilt wird über „Stand als Datei teilen“
und „Stand aus Datei laden“.
