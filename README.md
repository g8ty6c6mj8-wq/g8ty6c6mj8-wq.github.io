# Gassenplan

Hallenplan mit 31 Gassen (rechts 1–19 von vorne nach hinten, links 20–31 von hinten nach vorne),
Zwischenplätzen, Modellen und Chargen. Läuft im Browser und als Home-Bildschirm-App ohne Internet.

App: https://g8ty6c6mj8-wq.github.io/

Einträge liegen zuerst auf dem Gerät. Mit einem GitHub-Schlüssel (nur Zugriff auf das private
Projekt `gassenplan-daten`, Berechtigung „Contents: Read and write“) gleichen alle Handys ihren
Stand über die Datei `daten.json` in diesem Projekt ab. Der Schlüssel wird nur auf dem Handy gespeichert.
